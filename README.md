# HeritageHub Shopping Website

A responsive front-end shopping website inspired by the two reference screenshots supplied for the HeritageHub project.

## Run the website
1. Extract `HeritageHub-Website.zip`.
2. Open the `HeritageHub` folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click inside the editor and choose **Open with Live Server** (if the Live Server extension is installed).
   - Or double-click `index.html` to open it in your browser.

## Features
- Traditional Indian craft-inspired shopping catalogue
- Responsive product cards and category navigation
- Product search and sorting
- Wishlist and cart with quantity controls
- Cart and wishlist saved in browser local storage
- Sign-in / create-account demo modal
- Demo checkout and newsletter form
- Mobile-friendly layout

## Important project note
This is a front-end student-project demonstration. Login, Google/Facebook buttons, newsletter, checkout and order placement are simulated in the browser. There is no server, database, real payment gateway, or real social login. Product names, prices, ratings and craft descriptions are sample content. The images are loaded from Unsplash, so an internet connection is needed for those images and Google Fonts.

## Suggested next development stage
Connect the interface to a backend such as Python Flask or Node.js, a database such as MySQL, and a secure payment provider's test environment. Never store real passwords in browser local storage.
